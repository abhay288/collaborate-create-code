# AVSAR – One-Stop Personalized Career & Education Advisor

![AVSAR Logo](https://ibb.co/DH8LLtYc)

AVSAR is an AI-powered career guidance and educational recommendation platform designed to help students after **10th, 12th, and Graduation** make informed decisions about their **career paths, courses, colleges, and scholarships**.

---
## 🌐 Live Demo
(https://collaborate-create-code.vercel.app/)


## 🚀 Features

### 🎯 AI-Based Career Recommendations
- Personalized guidance using ML models (Scikit‑learn, TensorFlow Lite, PyTorch)
- Generates best-fit careers, courses, and branches

### 🧠 Adaptive Aptitude Quiz
- Dynamic, profile-based questions
- Skill-wise breakdown (Logical, Verbal, Technical, Creativity, Numerical)

### 🎓 College Recommendation System
- State-wise and district-wise search
- Nearby colleges via Google Maps API
- Government & private college filtering

### 💰 Scholarship Finder
- Verified scholarships (NSP, UP Scholarship, Buddy4Study)
- Eligibility-based filtering

### 🧭 Student Onboarding
- Captures background, interests, goals, and location
- Tailors results accordingly

### 🛡 Secure Authentication
- Supabase Auth (Email/Github/Google)
- Encrypted handling of user data
